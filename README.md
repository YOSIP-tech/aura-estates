## AURA ESTATES — Luxury Real Estate Website

**Premium Real Estate · Website Design & Development**

A modern, responsive website concept for a luxury real estate brand on Spain's Costa del Sol.

Designed in Figma and developed with HTML, CSS, and JavaScript, the project includes a premium homepage, a property catalog with interactive filters, individual property detail pages, and a contact experience.

**Project highlights**
- Premium, editorial-inspired visual design
- Responsive desktop and mobile layouts
- Interactive property filtering and sorting
- Dynamic property detail pages
- Reusable UI elements and accessible navigation

**Technology:** Figma, HTML5, CSS3, JavaScript, GitHub Pages.

*Portfolio concept. The real estate brand, listings and prices are fictional.*
